# 多平台标题字数与写法依据

核对日期：2026-08-14。

## 先区分两类数字

- **平台字段上限**：编辑器或 API 是否允许发布，是技术边界。
- **建议标题长度**：信息流能否完整展示、用户能否扫一眼读懂，是运营边界。

不要把运营建议写成“官方硬限制”。平台会调整字段和展示方式，实际发布前仍要以当时的编辑器提示为准。

## 公众号

- 公众号草稿 API 的公开接口资料通常将标题记为最多 64 字符；这是发布字段参考上限，不是推荐写满的长度。
- 本 Skill 的 TOP50 语料显示：高表现标题主力落在 22-27 字，Top10 均值约 25 字，30 字作为交付上限更适合微信列表展示。
- 默认输出 5 条：3 条 22-27 字，2 条 28-30 字。前 15 字必须出现主体和阅读理由。
- 公众号贴图不受标题字段限制，但为保证图片上能放大、扫读，按最多 20 字交付，并与小红书共用一组短标题。

## 小红书

- 公开的小红书企业号创作指南建议标题控制在 15-20 字，避免过长后隐藏；当前常见编辑器限制也按 20 字执行。
- 默认输出 5 条，每条最多 20 字，优先落在 15-20 字。
- 前 10 字放具体产品、品类、场景或人群关键词；后半句只放一个结果、收益或真实反差。
- 不默认堆 emoji，不在标题里塞话题标签，不用无法由正文证明的效果承诺。

## 抖音

- 抖音不同入口把文字字段称为“标题”“描述”或“信息流卡片标题”，上限并不统一。公开的跨平台统计常把普通作品描述记为 55 字；抖音开放平台的信息流卡片规范则建议标题 7-35 字。这两者不能混为一个统一硬限制。
- 为了推荐流扫读和视频前 3 秒协同，本 Skill 默认输出 5 条，建议 8-18 字，交付上限 20 字。
- 前 5-8 字放冲突、痛点、结果或利益；标题必须能被封面和视频开头兑现。
- 避免题文不符、名词堆砌、模糊指代、连续标点和无依据夸大。

## 输出数量

- 公众号正文标题：5 条。
- 小红书/公众号贴图通用标题：5 条，不拆成两组。
- 抖音标题：5 条。
- 用户只指定一个平台时，只输出对应 5 条。
