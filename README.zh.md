## 🌟 为什么做这个 Skill？

写过公众号的朋友都知道：**文章写得再好，标题不行，就是没人点开。**

我是「沃垠AI」的博主。2026 年，这个号写了100篇原创文章，我们从中挑选了TOP50 的热门文章。这些标题没有一条靠“震惊”“揭秘”，也没有一条是拍脑袋想出来的。

于是我把这 50 条标题连同阅读量、分享数、分享率全部拉出来，逐条拆解：字数分布、断句结构、点名方式、数字用法、标点频率、用词偏好……最后**反推出一套完整的标题方法论，封装成了这个 Skill**。

它不是一份“标题写作指南”那样的正确废话，而是一套**带数据、可校验、能直接跑**的规则系统：每一条规则后面，都站着真实的阅读量、转发和留言数据。

> 如果你也相信：好标题不是灵感，是统计学。欢迎你来用、来改、来 Star。

## ✨ 它能做什么？

丢给它一篇文章草稿、一句话选题，或者一个待优化的旧标题，它会输出：

- **6-8 个公众号正文标题候选**，覆盖短版（15-20 字）、标准版（22-27 字）、完整版（28-30 字）
- **公众号贴图 + 小红书标题**：额外给出贴图文案和小红书标题，两类都不超过 20 字
- **每条标注准确字数、所用范式和传播目标**，可以直接挑、直接用
- **推荐首选 + 理由**，告诉你为什么这条最适合这篇文章
- **传播目标明确标注**：每条直接标明主打冲阅读或冲分享涨粉，避免不同分组重复同一标题
- **旧标题诊断**：如果给的是旧标题，先一两句点出具体问题（超长 / 没点名 / 没数字 / 后半段重复），再给候选，让你看到改动的逻辑

## 🧠 核心发现：阅读和涨粉是两个目标

这个 Skill 的灵魂，是 TOP50 数据里一个反直觉的分裂：

> **阅读量最高的标题类型，分享率一般较低；分享率高的标题，往往更能涨粉。**

| 文章类型 | 典型阅读量 | 分享率 | 说明 |
| - | - | - | - |
| 干货教程 / 清单盘点 | 1.5-8 万 | **13-19%** | 分享率天花板，读者喜欢收藏，容易涨粉 |
| 新模型速报 | **10-24 万** | 4-6% | 阅读天花板，靠时效爆发 |
| 第一人称作品 | 1-5.5 万 | 3-8% | 靠人格和"代价"背书，涨粉秘诀 |
| 横评实测 | 1.5-3 万 | 2-4% | 真横评内容首选 |
| 行业观点 / 颠覆叙事 | 2.5-14.5 万 | 1.5-3% | 能爆阅读，但不涨粉 |

所以它起标题的第一步不是想词，而是先定目标：**这篇要冲阅读，还是要冲分享涨粉？** 目标不同，选的范式完全不同。

## 🛠️ 技术架构：它是怎么工作的

这个 Skill 采用「指令 + 参考语料」的渐进式披露（Progressive Disclosure）结构，三个文件各司其职：

```
┌────────────────────────────────────────────────────────────┐
│                        SKILL.md                            │
│  主指令文件：四步工作流 + 输出契约                            │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ 第一步 定目标 → 拉阅读 or 拉分享涨粉？                  │  │
│  │ 第二步 选范式 → 六大范式，每个出 2-3 个候选             │  │
│  │ 第三步 硬规则打磨 → 字数 / 结构 / 点名 / 数字 / 标点     │  │
│  │ 第四步 自检 → 7 条清单，答"否"就重写                   │  │
│  └──────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────┘
          │                                    │
          ▼                                    ▼
┌───────────────────────┐        ┌───────────────────────────┐
│ references/lexicon.md │        │  references/corpus.md     │
│ 高频词库：决定"味道"  │        │ 50 条标题全量语料          │
│ 起题前必读             │        │ 阅读/分享数据 + 范式归类   │
└───────────────────────┘        └───────────────────────────┘
```

### 六大标题范式

所有范式都从语料中归纳，并标注了对应的真实数据：

| 范式 | 公式 | 代表标题（真实数据） |
| - | - | - |
| 1 新品速报 | 定位 + 点名 + 来了！+ 最低门槛承诺 | 中国版Codex来了，Qwen3.7-Max免费用！ |
| 2 保姆级干货 | 强度标记 + 主题 + 一站式承诺 | 万字干货！Agent Skills从入门到精通 |
| 3 清单盘点 | 最值得X的N个品类 + 反差评价 | 最值得推荐的20个宝藏Skills，小众但真香 |
| 4 第一人称战绩 | 量化代价 + 我做出了什么 + 免费开源 | 烧了10亿Token，我做了一个Markdown编辑器，开源免费 |
| 5 横评实测 | 实测 + 3-4 个产品名 + 意外结论或成本 | 横评Opus 4.8、GPT-5.5、DeepSeek V4，356元测出来的真实排名 |
| 6 行业观点 | 时间/规模锚点 + 被颠覆的事 + 情绪词 | 40年没变过的Email，被腾讯重新定义了 |

### 硬规则（不是风格偏好，是统计事实）

- **字数**：正文标题覆盖短版 15-20 字、标准版 22-27 字、完整版 28-30 字；贴图和小红书最多 20 字
- **前 15 字必须独立成立**：微信列表页会截断，最强信息要压在最前面
- **点名**：92% 的爆款标题含具体模型/产品名，而且带版本号（Qwen3.7-Max，不是"某大模型"）
- **数字**：56% 含阿拉伯数字；8、16 这种"非整数"比整数更可信——它暗示你真数过
- **标点**：80% 用逗号切 2-3 段；感叹号最多 1 个；问号只在真痛点时用
- **禁用词**：语料里 0 条使用"震惊""揭秘""不看后悔""封神了"这类空洞标题党词

### 双参考文件设计

- **`lexicon.md`（词库）**：决定标题的"味道"。开场爆发词、门槛承诺、干货强度标记、第一人称动词（要糙：搓了一个、跑通了、烧了）、悬念收尾、禁用词清单。**起题前必读**——用错一个词，整条标题就露 AI 味。
- **`corpus.md`（语料库）**：50 条标题的完整榜单，含字数、阅读、分享、分享率、范式归类、发布日期。拿不准某个范式怎么落地时，翻它找同类对照。

## 🚀 快速开始

### 安装

```
# 克隆仓库
git clone https://github.com/woyin2024/lengyi-title.git
```
将整个 `lengyi-title` 文件夹放入你 Agent 的 Skills 目录：
-  **Claude Code 路径**：`C:\Users\Administrator\.claude\skills`
- **Codex 路径**：`C:\Users\Administrator\.codex\skills`
- **WorkBuddy 路径**：`~/.workbuddy/skills`
- **其他 Agent**：参照你所用工具的 Skill 安装说明

### 使用

装好后不用再记任何规则，直接用自然语言：

```
“帮这篇文章起几个公众号标题：[粘贴正文]”
“这个标题帮我优化一下：[旧标题]"”
“我想写一篇豆包隐藏玩法的清单文，主要是涨粉，帮我想几个题目”
“再给我公众号贴图文案和 20 字内的小红书标题”
“用lengyi-title skill给这篇文章起标题”
```

Agent 会自动加载 Skill，按「定目标 → 选范式 → 三档字数改写 → 平台适配 → 自检」的流程输出完整标题包。
